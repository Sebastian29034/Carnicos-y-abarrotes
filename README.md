# 🥩 Cárnicos & Abarrotes Don Marcos

Sitio web moderno y responsive para una tienda de cárnicos y abarrotes. El proyecto fue desarrollado utilizando tecnologías web básicas como HTML, CSS y JavaScript, ofreciendo una experiencia visual atractiva e interactiva para los usuarios.

---

## 📌 Características

- Diseño moderno y responsive.
- Navegación adaptada para dispositivos móviles.
- Catálogo de productos.
- Sección de galería.
- Formulario de contacto interactivo.
- Animaciones suaves con JavaScript.
- Sistema visual de agregado al carrito.
- Barra de navegación dinámica.
- Botón de regreso al inicio.
- Efectos de scroll y animaciones de aparición.

---

## 🚀 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript Vanilla

---

## ▶️ Cómo ejecutar el proyecto

1. Clona este repositorio:

```bash
git clone https://github.com/tu-usuario/tu-repositorio.git
```

2. Ingresa a la carpeta del proyecto:

```bash
cd Abarrotes
```

3. Abre el archivo `index.html` en tu navegador.

También puedes usar extensiones como **Live Server** en Visual Studio Code para una mejor experiencia.

## ✨ Funcionalidades implementadas

### 🧭 Navegación dinámica
- Menú hamburguesa para móviles.
- Resaltado automático de la sección activa.
- Navbar con efecto al hacer scroll.

### 🛒 Simulación de carrito
- Contador visual de productos agregados.
- Notificaciones tipo toast.

### 📩 Formulario interactivo
- Simulación de envío.
- Mensaje de confirmación visual.

### 🎨 Efectos visuales
- Animaciones con Intersection Observer.
- Efectos de parallax.
- Aparición gradual de elementos.
